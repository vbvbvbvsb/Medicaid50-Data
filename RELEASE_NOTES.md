Medicaid50 Data v1.0.1 — automated release publishing.

This patch release publishes the dataset through the version-tag GitHub Actions workflow. The workflow validates the tagged snapshot and matching release metadata, builds the ZIP and SHA-256 checksums, and publishes only after validation passes.

- 51 jurisdictions: all 50 states and DC.
- 60 managed-care route/contact records, 436 sources and 21 portals.
- 358 practitioner answer sections and 230 open practitioner questions.
- Full JSON, schema, 10 CSV exports, source provenance and attribution.

Dataset fact values, source records, evidence dates and scope qualifications are unchanged from v1.0.0. Packaged November 16, 2026; packaging did not reverify external sources. Practitioner confirmations remain attributed.
